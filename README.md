# 聲控對戰 Voice Fight

兩支手機連到同一台電腦，各自挑一位 Q 版俠客，找出文字方塊中相連的招式名稱、**對著麥克風念出來**來出招。

- 電腦是伺服器，首頁只顯示**房間號碼**和 **QR Code**
- 一個房間最多兩人：**先進房的在左方、後進房的在右方**
- 手機畫面上半部是對戰場景，下半部是像 Candy Crush 一樣的文字方塊
- 出招時兩支手機會同步播放施招動畫、受擊動畫，並同步消除方塊，畫面保持一致

## 快速開始

```bash
npm install
npm start
```

1. 電腦瀏覽器開啟 **http://localhost:3000**，畫面會顯示房間號碼和 QR Code。
2. 手機和電腦連到**同一個 Wi‑Fi**，用手機掃描 QR Code（或開啟畫面上顯示的網址並輸入房號）。
3. 第一次連線時手機會跳出**憑證警告**，因為伺服器用的是自簽 HTTPS 憑證（手機要在 HTTPS 下才能使用麥克風）：
   - Android Chrome：「進階」→「繼續前往」
   - iPhone Safari：「顯示詳細資訊」→「造訪此網站」
4. 兩人選好角色並按「準備」後倒數 3 秒開戰。

> 電腦如果有多張網卡、QR Code 上的 IP 不對，可以自己指定：`HOST_IP=192.168.1.20 npm start`
> 連接埠可用 `PORT`（預設 3000）和 `HTTPS_PORT`（預設 3443）調整，記得讓防火牆放行。

### 語音辨識需求

使用瀏覽器內建的 Web Speech API（繁體中文 `zh-TW`）：

| 裝置 | 需求 |
| --- | --- |
| Android | Chrome，**手機要能上網**（辨識由 Google 語音服務處理） |
| iPhone | Safari 14.5 以上，並在設定中開啟 Siri／聽寫 |

不能用麥克風時，可以在「招式表」裡開啟**手動點選方塊出招**當作備援：依序點選相連的字，再點一次最後一格出招。

## 玩法

| 操作 | 說明 |
| --- | --- |
| 🎤 按住念招式 | 集氣條滿了以後，按住麥克風念出招式名稱，放開送出（輕點一下則說完自動結束） |
| ⚔️ 普攻 | 隨時可以按，冷卻 1.2 秒，傷害取決於**武術** |
| 📜 招式表 | 列出你的全部招式，✓ 表示目前盤面上找得到 |
| 念「重置」 | 找不到招式時重新洗牌，**每人每場 1 次** |

- 招式名稱的字必須**相連**（上下左右或斜角），而且同一格不能重複用。
- 只能念**自己角色**的招式。念對以後方塊會消除、上面的方塊往下掉，再從頂端補上新的字。
- 語音比對用拼音、不分聲調，聽成同音字也算數（例如「玉劍」→ 御劍），另外也容忍台灣口音：zh/z、ch/c、sh/s、n/l、in/ing、en/eng 不分。四字招式允許聽錯一個字。

### 盤面保證有招式可念

伺服器每次補字以後都會檢查盤面，確保**雙方各自至少有 2 個自己的招式**可以念（開局時是 3 個）。如果不夠，就把缺少的招式「種」進盤面：優先種在剛掉下來的新格子，並避開其他現存招式的路徑，讓已經看到的字盡量不變。單元測試會連續消除 2000 次來驗證這個保證。

## 屬性

| 屬性 | 影響 |
| --- | --- |
| 血量 | 氣血上限 |
| 武術 | 普攻傷害 |
| 靈力 | 招式傷害與回復量 |
| 身法 | 集氣速度 |
| 吉運 | 所有隨機結果：傷害浮動偏高、暴擊率、閃避普攻、加血加成、減益持續時間 |
| 防禦 | 減傷：`傷害 × 80 / (80 + 防禦)` |

## 角色

造型參考《仙劍奇俠傳一》和《軒轅劍外傳 天之痕》的 2D Q 版人物。名稱與美術都是原創，人物以 Canvas 程序繪製，沒有使用任何外部圖檔。

| 角色 | 定位 | 血 | 武 | 靈 | 身 | 運 | 防 | 招式 |
| --- | --- | --- | --- | --- | --- | --- | --- | --- |
| 凌風 | 御劍少俠（原型 李逍遙） | 1005 | 64 | 56 | 55 | 50 | 50 | 御劍、劍氣斬、醉仙步、天罡戰氣、萬劍歸宗 |
| 靈月 | 女媧後裔（原型 趙靈兒） | 915 | 42 | 72 | 52 | 52 | 44 | 雷咒、冰心訣、天雷破、五氣朝元、冰封千里 |
| 紅綾 | 鞭影俠女（原型 林月如） | 1010 | 70 | 44 | 56 | 45 | 50 | 鳳舞、怒火、連環鞭、破甲擊、流星趕月 |
| 阿蠻 | 苗疆蠱女（原型 阿奴） | 965 | 46 | 60 | 60 | 66 | 44 | 蠱毒、噬魂、銀鈴咒、百草回春、萬蠱蝕天 |
| 靖遠 | 符劍少年（原型 陳靖仇） | 1035 | 55 | 55 | 48 | 46 | 62 | 符火、破軍斬、鎮妖符、真元護體、雷霆萬鈞 |
| 玉兒 | 草原神箭（原型 拓跋玉兒） | 1000 | 62 | 52 | 62 | 54 | 46 | 風行、狼嘯、穿雲箭、連珠箭、鷹擊長空 |

招式越長威力越大（2 字 ≈ 1.0、3 字 ≈ 1.35、4 字 ≈ 1.8 倍），因為越長的招式在盤面上越難找。

### 平衡調校

`npm run balance` 會用真實的對戰邏輯讓機器人兩兩對打。機器人一直普攻，集氣滿後要花 1.5～4.5 秒「找字」才出招，左右各打一半。目前的數值下，各角色總勝率都在 **48%～52%**，平均一場約 50 秒。調整角色數值後可以重跑確認。

## 專案結構

```
server/
  index.js    HTTP + HTTPS 伺服器、Socket.IO、房間管理、QR Code
  room.js     房間：進房順序、選角、倒數、斷線重連（30 秒內）、再戰
  game.js     即時戰鬥邏輯（伺服器權威）：集氣、傷害公式、增減益、持續傷害
  board.js    文字方塊：八方向路徑搜尋、掉落補字、保證有招式的演算法
  speech.js   語音結果比對（拼音、同音字、口音容錯）
public/
  index.html  電腦端首頁（房號 + QR Code）
  play.html   手機端
  shared/characters.js  角色與招式資料（前後端共用）
  js/sprites.js   Q 版人物繪製與動作（待機、普攻、施招、受擊、倒地、勝利）
  js/scene.js     對戰場景與 26 種招式特效
  js/boardview.js 方塊棋盤動畫
  js/voice.js     Web Speech API 包裝
scripts/balance.js  平衡模擬
test/               單元測試（npm test）
```
