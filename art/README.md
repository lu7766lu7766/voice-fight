# 美術圖：用 Gemini 生成角色立繪與特效圖

遊戲會自動使用 `public/img/` 裡的圖片。沒有圖的部分會退回程式繪製，所以可以一張一張慢慢補。

流程：

1. 用下面的提示詞請 Gemini 生圖。
2. 把原始圖照下表的檔名放進 `art/raw/`（png、jpg、webp 都可以，不用自己去背或裁切）。角色圖也可以直接放 `art/<角色id>/`，例如 `art/xiaoyao/idle.jpeg`。
3. 執行 `python3 scripts/art.py`（需要 `pip install pillow numpy`）。腳本會自動去背（包含頭髮、手臂圍住的背景空隙）、裁切、對齊腳底位置、縮小檔案，並產生 `public/img/manifest.json`。同一角色的動作圖以待機圖的腳底位置對齊，所以 4 張圖請用相同構圖。
4. 重新整理手機頁面就會看到新圖。

```
art/raw/
  chars/xiaoyao/idle.png   李逍遙 待機（必要）
  chars/xiaoyao/attack.png       出招
  chars/xiaoyao/hurt.png         受傷
  chars/xiaoyao/win.png          勝利
  chars/xiaoyao/cast.png         施法：劍訣前指（選做，御劍用）
  chars/xiaoyao/cast_up.png      施法：劍訣高舉（選做，萬劍歸宗、天罡戰氣用）
  chars/linger/…   趙靈兒      chars/yueru/…    林月如
  chars/anu/…      阿奴        chars/jingchou/… 陳靖仇
  chars/yuer/…     拓跋玉兒
  fx/sword.png  fx/eagle.png …   特效圖（檔名見下方）
  bg.png                         戰鬥背景
```

每個角色只有 `idle` 是必要的。其他動作缺圖時，會用 `idle` 加上位移、傾斜和染色代替；`cast_up` 缺圖時用 `cast`，`cast` 缺圖時用 `attack`。
原始圖處理完可以刪掉，已經產生在 `public/img/` 的圖會保留。

## 一、角色立繪（6 角色 × 4 張）

### 共同規格（每次都要貼在提示詞後面）

```
【畫面規格】
- Q 版 2.5 頭身 2D 遊戲角色立繪，古風武俠，賽璐璐上色，乾淨的深褐色外框線，色彩飽和明亮。
- 全身入鏡，角色身體朝向畫面「右側」（3/4 側面），臉朝右。
- 角色置中，從頭頂（含頭飾）到腳底約占畫面高度 85%，雙腳貼近畫面下緣但不要被切掉。
- 背景是完全均勻的純綠色 #00FF00：不要地面、不要影子、不要漸層、不要特效光、不要文字、不要邊框。
- 正方形 1:1，1024×1024。
```

> 如果角色衣服有大面積亮綠色，背景改用純洋紅色 #FF00FF。
> 同一個角色的 4 張圖請用相同的解析度和構圖（角色大小一致），遊戲才不會在動作切換時忽大忽小。

### 讓 4 張動作長得一樣的訣竅

1. 先生成「待機」那張，滿意後再做其他動作。
2. 生成其他動作時，把待機圖一起上傳，開頭寫：「**這是同一個角色，保持完全相同的臉、髮型、服裝、配色與畫風，只改變動作：**」，後面接動作描述和共同規格。
3. 想要更像原作，可以同時上傳一張原作官方立繪當參考，並寫「造型參考附圖，但畫成 Q 版」。

### 動作描述

| 檔名 | 動作描述（接在角色描述後面） |
| --- | --- |
| `idle` | 戰鬥待機站姿，雙腳微開站穩，武器擺在身前備戰，表情自信。 |
| `attack` | 出招瞬間：身體前傾、往右跨步，武器或施法的手大力往右前方揮出，衣襬和頭髮被動作帶起，表情專注吶喊。 |
| `hurt` | 被擊中的瞬間：身體往後（往左）仰，一隻手護在身前，閉眼皺眉、表情痛苦，頭髮往前甩。 |
| `win` | 勝利姿勢：開心地笑，一手舉起武器或比出得意的手勢，充滿精神。 |
| `cast` | （李逍遙）御劍施法：雙手空著、畫面上不要出現劍。右手食指與中指併攏成劍訣，向右前方伸直指出；左手捏劍訣收在胸前，弓步、身體略前傾，頭髮與披風向後吹起。 |
| `cast_up` | （李逍遙）御劍施法：雙手空著、畫面上不要出現劍。右手劍訣高舉過頭指向右上方，左手捏劍訣在胸前，頭髮與披風被氣流向上揚起。 |

## 二、特效圖（選做，可以大幅提升特效質感）

目前所有特效都由程式繪製，這幾張圖會換掉程式畫得比較陽春的部分。

### 共同規格

發光類特效（大部分）：

```
【畫面規格】
- 2D 遊戲技能特效素材，古風仙俠風格，發光、半透明、帶有光暈與細小光粒。
- 背景是完全純黑色 #000000，沒有其他東西、沒有文字、沒有邊框。
- 主體置中、完整不被切掉，四周留一點黑色空間。
```

實體物件類（符咒、銀鈴）：背景改成「完全均勻的純綠色 #00FF00，不要影子」。

## 三、戰鬥背景（選做）

```
2D 遊戲戰鬥場景背景，古風仙俠山水，黃昏到夜晚的天色（紫色與橘粉色漸層天空、一輪明月），
遠方有水墨層次的群山與小亭子，近景是平坦的草地。
畫面下方約 15% 是平坦的地面，角色會站在那裡；畫面中央不要放任何顯眼的物體。
不要人物、不要文字、不要邊框。16:9 橫式，1920×1080。
```

地面位置如果不在下方 15%，跑腳本時指定，例如 `python3 scripts/art.py --ground 0.8`（0~1，由上往下量）。
